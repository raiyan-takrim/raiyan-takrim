## Featured Projects

### [TripBuddy API](https://github.com/raiyan-takrim/trip-buddy)
> **Java 17 · Spring Boot · Spring Data JPA · PostgreSQL · OpenAPI/Swagger**

An enterprise-grade RESTful backend for an intercity bus reservation system — handling route scheduling, real-time seat inventory, and full booking lifecycles.

- Engineered a concurrency-safe booking engine using **PostgreSQL Pessimistic Write Locks**, eliminating 100% of double-booking conflicts under simultaneous high-traffic requests
- Automated seat release via **Spring `@Scheduled` cron jobs** enforcing a 10-minute hold TTL — zero manual intervention
- Centralised exception handling with `@RestControllerAdvice`, cutting controller boilerplate by **40%+**
- Enforced strict **DTO separation** between database entities and API response layers for security and mutation control
